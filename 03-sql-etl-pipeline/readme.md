# SQL Database Optimization & Incremental Ingestion
---
SQL analytics pipeline demonstrating relational schema design, advanced analytical queries (CTEs, Window Functions), index optimization, and incremental update mechanisms for high-volume database operations.

# 🛠 Tech Stack & Tools
* **PostgreSQL / MySQL:** Relational database management.

* **SQL Query Optimization:** Indexes, CTEs, Window Functions (ROW_NUMBER, SUM OVER).

* **ETL Pipeline Integration:** Timestamp-based incremental ingestion logic (NOW() - INTERVAL '24 hours').

# 📂 Repository Contents
* **schema_and_queries.sql:** Schema definitions, indexes, and complex analytical SQL queries.
